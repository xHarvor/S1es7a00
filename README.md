# ¡Hola! Soy Daniel Toledo 👋

Soy estudiante de Ingeniería en Sistemas Computacionales en el **Tecnológico Nacional de México (TecNM)** con un fuerte enfoque en bases de datos, desarrollo de proyectos IoT y entornos Linux con enfoque en desarrollo web. 

## 🚀 Sobre mí

* 🎓 Tengo 20 años y me apasiona desarrollar soluciones tecnológicas, desde la programación de firmware hasta la estructuración de bases de datos.
* 🐧 Soy usuario de **Arch Linux**, donde disfruto configurando mis dotfiles, gestionando paquetes (pacman, yay, paru) y personalizando mi entorno con **Hyprland**.
* 🤝 Trabajo en desarrollo colaborativo de forma constante, participando activamente con mis compañeros en el

  **Equipo Gecko** y el **Equipo Mondongo**.
* ⚡ Siempre estoy buscando optimizar el rendimiento, tanto en el código que escribo como en el hardware que utilizo.

## 💻 Stack Tecnológico

* **Bases de Datos:** PostgreSQL, MariaDB, Oracle, SQL Server.
* **Hardware & IoT:** Programación de firmware, ensamblaje de hardware y trabajo con microcontroladores **ESP32**.
* **Desarrollo Web & Herramientas:** HTML, CSS, Git, GitHub.
* **Sistemas Operativos:** Linux (Arch).

## 🛠️ Proyectos Destacados

* **Vorare (anteriormente EcoHawk):** Desarrollo de una estación de carga inteligente. El proyecto abarca desde el ensamblaje del hardware con ESP32 y sensores de monitoreo de energía, hasta la codificación del firmware.
* **Desarrollo Web Client-Side:** Creación y gestión de portafolios web profesionales.

## 🎮 Más allá del código...

Cuando no estoy escribiendo código o administrando bases de datos, me dedico al hardware y al modding. Disfruto exprimir al máximo mi PC, lubricar switches para teclados mecánicos, probar mouses ultraligeros para gaming y jugar en Steam.
